## PROJECTS

### 01 — Banque Unity & CyberShield AI

**Financial security · Machine learning · Web dashboard**

A cybersecurity project combining a web dashboard and machine-learning techniques to explore suspicious activity and anomaly detection.

- Flask REST API and PHP dashboard.
- Machine-learning approaches explored: Isolation Forest, One-Class SVM, Autoencoder and Local Outlier Factor.
- Security scenarios include DDoS, brute-force attempts, SQL injection and suspicious financial activity.

Repository: [banque-unity-cybershield-aiv1](https://github.com/waalidcyber/banque-unity-cybershield-aiv1)

### 02 — NeuroSecure

**Application security · Intelligent detection**

A security-oriented application project involving web technologies, database integration and machine-learning experimentation.

- Flask and MySQL.
- Exploration of web security, detection mechanisms and authentication.
- Project documentation and results should be interpreted according to the actual test environment.

### 03 — Khouribga Portal

**Web development · Database · Application architecture**

A web application project using modern frontend and backend technologies.

- React frontend.
- Express backend.
- PostgreSQL and Prisma.
- French and Arabic interface considerations.
